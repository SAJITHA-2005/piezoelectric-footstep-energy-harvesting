# Enhanced Piezoelectric Footstep Energy Harvesting for Self-Powered IoT Systems

## Problem
Millions of footsteps generate mechanical energy that is wasted while IoT devices depend on batteries and grid power.

## Solution
A piezoelectric energy harvesting system using SSHI, boost conversion, and energy storage to power low-power IoT devices.

## Features
- Piezoelectric footstep energy harvesting
- SSHI efficiency enhancement
- Boost converter
- Supercapacitor/Battery storage
- IoT sensor powering

## Hardware Stack
- Piezoelectric discs
- SSHI circuit
- Full-wave rectifier
- Boost converter
- Supercapacitor
- ESP32/Arduino

## Software Stack
- Python
- Arduino IDE
- ESP32 Framework
- Flask Dashboard

## Results
- Harvested energy from human footsteps
- Improved extraction efficiency using SSHI
- Suitable for low-power IoT applications
